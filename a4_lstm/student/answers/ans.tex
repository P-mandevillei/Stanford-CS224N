\section{Neural Machine Translation with RNNs}
\subsection*{(g)}
  The masks set the attention score to $-\inf$ at the positions of the pad tokens. When computing the softmax, these attention scores become 0, which means that the source encodings of the padding does not contribute to the decoder predictions. This is necessary because the decoder needs only to attend to actual information in the source sentence. The pad tokens will only add noise to the prediction and should not be added.
